## 🎨 Customization

### Personal Information
Edit the following in `index.html`:

- **Profile Image**: Replace the `src` attribute in the `<img>` tag
- **Name**: Update the profile name and title
- **Location, Age**: Modify the info grid values
- **Social Links**: Update href attributes in the social links section

### Skills & Expertise
In the skills section, you can:
- Add new skills by copying a skill-item div
- Change skill names and icons
- Use Font Awesome icons for consistency

### Social Links
Update your social media links:
- Telegram: Already configured
- GitHub: Add your GitHub profile URL
- Discord: Add your Discord handle
- Instagram: Add your Instagram profile

### Colors & Theme
Modify CSS variables in the `:root` section:
```css
:root {
    --primary-color: #00ffcc;    /* Main accent color */
    --secondary-color: #ff6b6b;  /* Secondary accent */
    --accent-color: #4ecdc4;     /* Additional accent */
}
```

### Background Video
Replace the video URL in the `<video>` tag:
```html
<source src="YOUR_VIDEO_URL" type="video/mp4">
```
